Modeling code for paper "Sharpening ion-channel nonlinearity increases mechanotransduction fidelity in the
ear’s sensory cells"

The code has been developed using Mathematica 13.0.

The code is subdived into different sections. Each sections corresponds to a figure in the paper. Each section can be run on its own after running the first section that defines the parameters, the functions, the plot settings and the simulation of the equations.
